CodeIt

A browser coding studio for kids aged 8 to 14. A kid describes a game or website, AI builds a first version, and then they learn by editing the real code.

Top 5of 49 at Sheridan's 2025 capstone showcase
300+of the project's commits are mine
31sequenced Python lessons
3Claude model tiers, picked per build
Problem
Kids who outgrow block coding hit a wall with real code. Blank editors are scary, and tutorials don't let them build what they actually want.
Build
React front end with an in-browser code editor, a Node.js and Express API with JWT auth, and PostgreSQL on Supabase, deployed on Vercel. The AI builder runs on the Claude API across three model tiers chosen by how hard each build is, so simple pages stay cheap and harder games get the stronger model.
Running it
A free plan with 10 AI-assisted builds a month, and a CA$12 a month family plan through Stripe with plan limits. The backend is covered by automated tests. During development I moved the data layer from Azure SQL to MySQL on AWS RDS and then to PostgreSQL.
For parents
Comprehension questions are generated from each kid's own project, and parents get a plain-language summary instead of a score. Younger kids get a profile their parent manages, and projects stay private by default.
